Sistema de Gerenciamento de Abrigos e Resgates de Animais

Sobre o projeto

Projeto desenvolvido como Trabalho Final da disciplina de Programação Orientada a Objetos (POO), da Universidade Federal do Ceará (UFC) – Campus Crateús, período 2026.2.
O objetivo é desenvolver um sistema em Java para auxiliar ONGs e instituições de proteção animal no gerenciamento de animais resgatados, voluntários, veterinários e processos de adoção.

 Objetivos

- Organizar o cadastro de animais resgatados.
- Gerenciar usuários e suas permissões.
- Controlar processos de adoção.
- Registrar informações sobre a saúde dos animais.
- Organizar eventos e atividades voluntárias.
- Disponibilizar relatórios e estatísticas.

Tecnologias

- Java
- Programação Orientada a Objetos
- Git
- GitHub

Conceitos de POO
